# UI/UX 목업 규칙 (`LENSES`에 ui가 있을 때)

- **정적 목업**만: HTML·SVG 한 장, 실제 데이터 대신 표본 값. 인터랙션은 설명으로.
- 제안마다 **근거 접점(T-id)** 과 **잴 KPI**를 붙인다.
- 새 배지·열을 만들 때 **출처를 구분**한다: 모델 의견(LLM 추천·Jev 판정) · 앱이 센 숫자 · 사람 선택. 한 배지로 합치지 않는다.
- 추정 확률을 보여 줄 때는 “모델 의견” 라벨과 판단 없음(0.4–0.6) 표시를 같이.
- **자기보정 규칙**을 목업에 적는다: 무엇을 기록해 어떤 조건에서 표시를 바꾸거나 끄는가(예: 30건 뒤 일치율이 기준선보다 낮으면 숨김). 자동 전환은 사람 결정으로.
- 휴대폰 폭에서도 읽히게. 색만으로 상태를 전하지 않는다.
- 필수 목업 외에 **추가 아이디어 5개 이상**을 짧게(무엇 · 왜 · 비용).
